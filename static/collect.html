Pengumpulan data perangkat

Untuk mengirim hostname, user Windows, MAC address, dan port yang terbuka, unduh lalu jalankan skrip Windows pada perangkat ini. Skrip membaca informasi jaringan dan sistem perangkat ini, lalu mengirimkannya ke server.

Skrip membaca adapter jaringan aktif, port TCP yang mendengarkan, port UDP yang terikat, hostname Windows, dan akun Windows yang sedang menjalankan PowerShell. Jalankan dengan akun Windows biasa; jangan jalankan sebagai administrator kecuali diperlukan oleh kebijakan perangkat.

Unduh peluncur Windows (.cmd) — klik dua kali

Peluncur memerlukan koneksi internet ke server aplikasi. Ia menjalankan kolektor PowerShell hanya untuk proses tersebut dan menghapus salinan sementara setelah selesai; Execution Policy Windows tidak diubah.

Unduh kolektor PowerShell (.ps1) — jalankan manual

Untuk menjalankan manual: buka PowerShell di folder unduhan dan jalankan .\me-device-collector.ps1, sesuai kebijakan perangkat Anda.

Atau, kirim data browser

Opsi ini tidak dapat membaca MAC address, port, hostname, atau user Windows. Untuk informasi lengkap gunakan skrip Windows di atas.
